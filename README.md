# OpticRetail - Live Store Intelligence Dashboard

## Problem
While online e-commerce platforms track every session, click, and drop-off in real time, **offline physical retail stores remain a massive data blind spot**. 

OpticRetail solves this by ingesting raw, anonymized CCTV footage through an advanced detection pipeline (YOLOv8 + BoT-SORT) and outputting structured analytics. This frontend dashboard visualizes that data stream, providing store managers with real-time heatmaps, conversion funnels, and operational anomalies.

---

## Install
Ensure you have [Node.js](https://nodejs.org/) installed, then run:

```bash
# Clone the repository (if you haven't already)
git clone https://github.com/Kr1sh-gupta/OpticRetail.git
cd OpticRetail/frontend

# Install dependencies
npm install
```

---

## See It Work
Start the Vite development server to view the dashboard locally:

```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## Getting Started Path
Navigate through the sidebar to explore the different facets of the intelligence pipeline:

- 📊 **Overview**: High-level store KPIs (Conversion Rate, Total Visitors) and the daily store-to-purchase funnel.
- 📹 **Live Feeds**: View simulated CCTV camera streams augmented with the system's "Cyber Overlay" (bounding boxes and tracking IDs).
- 👥 **Audience**: Track spatial intelligence via the Live Store Heatmap and view unique visitor signatures generated by the Re-ID model.
- 🛒 **Conversions**: Analyze zone-by-zone revenue attribution and pinpoint exactly where financial leakage occurs (e.g., cart abandonment).
- 🚨 **Anomalies**: A visual feed of critical security and operational alerts (e.g., suspicious loitering, severe queue bottlenecks) captured as freeze-frames.

## How It Works

<details>
<summary><strong>Click to expand architecture details</strong></summary>

The frontend is intentionally designed as a lightweight, lightning-fast visualization layer to ensure it doesn't compete for resources with the heavy Computer Vision inference running on the backend.

- **Framework**: React + Vite + TypeScript.
- **Styling**: Pure CSS variables (`index.css`) establishing a premium, custom B2B SaaS dark theme without the bloat of heavy component libraries.
- **Real-Time Integration**: Designed to aggressively poll the FastAPI backend REST endpoints (e.g., `GET /stores/{id}/metrics`), ensuring metrics update live on screen while strictly adhering to the challenge's API contract requirements.
- **Graceful Degradation**: Built to handle "Zero-Traffic" windows seamlessly without crashing.

</details>
